# DanceFlow — resume bullets

- Extended an open-source Java/Spring Boot and Vue music platform, reusing its user and admin applications, MySQL persistence, and Redis-backed authentication to build DanceFlow.
- Implemented a three-section dance-practice playlist generator with three style mappings, millisecond duration budgeting, duplicate prevention, and authenticated transactional saving of real catalog songs.
- Added 130 backend unit/MVC test cases and a reproducible MySQL/Redis demo; verified generation, persistence, and retrieval against a 499-song catalog using real API and browser workflows.

These describe extensions, not authorship of the original platform. The 130 cases
include mocks and are not 130 real-service integration tests. No live LLM response,
audio playback, performance improvement or production security claim is made.
