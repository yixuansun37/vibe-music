# DanceFlow — resume bullets

- Extended an existing open-source Spring Boot/Vue music platform with authenticated dance-practice generation and transactional playlist saving, integrating a new Vue workflow with the inherited architecture.
- Implemented duplicate-free, duration-budgeted selection across three dance-style mappings and three practice sections, using real catalog metadata and a constrained optional AI-ranking adapter with explicit non-AI fallback.
- Added 130 backend unit/MVC test cases and a reproducible MySQL/Redis demo; verified generation, saving and retrieval against a 499-song catalog through real API and browser workflows.

These describe extensions, not authorship of the original platform. The 130 cases
include mocks and are not 130 real-service integration tests. No live LLM response,
audio playback, performance improvement or production security claim is made.
